# PDF form fixtures

Government forms, used as redistribution-safe AcroForm test fixtures:

- Austria: `at-neufoe2.pdf` (BMF NeuFoe 2; §7 Urheberrechtsgesetz).
- United States: `f1040.pdf`, `f941.pdf`, `f9465.pdf`, `f2848.pdf`, `f4506.pdf`, `fw2.pdf`, `g1145.pdf`, `irs_i9.pdf` (IRS/USCIS; public domain under 17 U.S.C. §105).

They cover text fields, checkboxes, dropdowns, date actions, JavaScript, encryption, dense layouts, and multi-page forms.

Sources: [BMF](https://formulare.bmf.gv.at/service/formulare/inter-Steuern/pdfs/9999/NeuFoe2.pdf), [IRS](https://www.irs.gov/forms-instructions), [USCIS](https://www.uscis.gov/forms).
